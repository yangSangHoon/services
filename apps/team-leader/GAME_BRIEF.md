# Game Brief: 버텨라, 팀장님

> Claude Code Game Studios `game-brief.md` 템플릿(minimal rigor: 이 한 장이 설계 문서 전부).

**One-sentence pitch:** 사방에서 날아오는 팀원 불만·지각·고객 컴플레인·상사의 무리한 지시·사장의 희망퇴직 압박을 방패 하나로 막으며 45세 팀장이 60세 정년까지 버티는 한 손 방어 게임.

## Core loop
- 사무실 한가운데 팀장 주위로 공격(말풍선)이 날아온다 → 손가락/마우스 방향으로 방패를 돌려 막는다.
- 막으면 연속 방어 콤보로 멘탈 회복, 못 막으면 멘탈 감소. 팀원의 응원(커피·치킨)은 일부러 **막지 말고** 받아야 회복.
- 1년(약 20초)을 버티면 연말 인사평가에서 특전 1개 선택 → 다음 해에는 새 공격 유형이 섞이고 더 빨라진다.

## Player goal & fail state
- 목표: 60세 정년퇴임(15년 생존). 기록 = 버틴 나이.
- 실패: 멘탈 0 → "53세, 희망퇴직 압박에 무너졌습니다"처럼 마지막에 맞은 공격이 퇴사 사유가 된다.

## MVP
1. 방패 회전(포인터 방향 / ← →) + 원형 충돌 판정
2. 공격 7종: 불만(직선), 지각(느리다가 돌진), 업무 태만(3연속 떠넘기기), 고객 컴플레인(아무 방향에서 빠름), 불합리한 지시(좌우로 흔들리며 접근), 희망퇴직 압박(느리고 묵직, 두 번 막아야 함), 응원(회복, 막으면 손해)
3. 공격 전 예고 모션(공격자가 "!" 표시하며 흔들림)
4. 15년 연도 진행 + 연도별 이벤트(신입 입사, 상무 부임, 구조조정…)
5. 연말 인사평가 특전 3택1
6. 정년퇴임 / 퇴사 결과 화면 + 공유

## Out of scope
- 로그인·랭킹·서버 저장 없음(최고 기록만 기기에 저장)
- 그래픽 에셋 없음: 이모지 + 캔버스 도형
- 스토리 컷신, 캐릭터 커스터마이즈, 멀티플레이 없음

## Build order
1. 방패 + 직선 공격 1종으로 "막는 손맛" 확인 (가장 위험한 부분)
2. 공격 7종 행동 패턴 + 예고 모션
3. 연도 진행·난이도 곡선, 특전
4. 결과 화면·공유·사운드·진동 다듬기

---
**Who it's for / what they feel:** 직장인이 출퇴근길 폰으로 5분 — "아 이거 우리 회사네" 하며 웃고, 정년까지 버텼을 때 묘한 뿌듯함.

**Art & audio direction:** 밝은 사무실 톤의 플랫 일러스트 느낌(이모지 캐릭터 + 파스텔 말풍선), 짧은 8비트 효과음.

**Reference game:** 방패로 사방 공격을 막는 원형 방어 장르 — 그중 "중앙 고정 + 방패 회전" 루프만 가져오고, 이동·공격은 없음.

## v2 개선 (2026-11-06, 스튜디오 리뷰 반영: game-designer + systems-designer)
- **51~59세 해마다 규칙 변주**: 연봉 동결(응원 없음) / TF장 추가 / 조직개편(10초에 자리 섞임) / 임금피크제(최대 멘탈 -15) / 후배가 상무로(지시 더 크게 흔들림) / 희망퇴직 2차(3번 막기) / 릴레이 공격 / 정년 직전 사장님 '마지막 면담'(3번 막기 → 팀원 응원 + 꽃가루)
- **유머 밀도**: 공격 대사 종류별 10~15개 + 50세 이후 대사, 막을 때 팀장 대응 멘트
- **공정성**: 예고에 공격 종류 아이콘 + 방패 바깥 방향 호, 반대편 동시 도착(0.25초·120°) 시 0.3초 미룸, 저프레임 터널링 판정 수정
- **첫 등장 안내**: 처음 보는 공격은 0.8초 슬로모션 + NEW 안내(기기에 기억)
- **연말 인사평가 등급** S/A/B/C(그해 맞은 횟수), S면 특전 후보 4개, 보유 특전 표시
- **특전 재조정**: 넓은 방패 +12°씩 최대 4번, 커피 빈도 +40%·회복 +25%, 1on1 → 팀원 피해 -25%, 알림 끄기 -50% + 전화벨 일찍, 평정심 최대 3번, 아직 안 나온 공격용 특전은 후보 제외
- **수치**: 스폰 1.0+0.085/년, 연초 대기 1초, 10연속 방어 +5, 상사·사장 대기 중이면 팀원 공격으로 대체, 7년차 혼합 완화
- **결과**: 칭호 15종 + 칭호 도감, 사직서/퇴직증명서 이미지 공유, 막을 때 진동·희망퇴직 히트스톱·연속 방어 단계 칭호

## v3 개선 (2026-11-06)
- **방패가 해마다 좁아짐**: 64°에서 1년마다 -1.8°, 최소 38° (45세 64° → 50세 55° → 59세 39°). '더 넓은 방패' 특전(+12°)은 그 위에 더해짐. 좁아진 해에는 연초 안내에 현재 각도 표시. 수치는 `game.ts` 의 `SHIELD_BASE_DEG / SHIELD_SHRINK_DEG / SHIELD_MIN_DEG`
- **판정점 표시**: 공격마다 빨간 작은 원(응원은 초록)이 실제 판정 위치. 이 점이 방패에 걸치면 막힘(허용 오차 = 점 반지름). 설명 말풍선은 점 옆(진행 방향과 수직)에 붙어서 따라옴, 화면 밖이면 반대쪽. 희망퇴직 남은 체력은 점 둘레 붉은 고리

## 막내 모드 (2026-11-11)

- 타이틀에서 **👔 팀장 모드 / 🐣 막내 모드** 선택 (마지막 선택 기억).
- 막내 모드 "버텨라, 막내야": **30세 신입 → 45세 팀장 승진**. 승진하면 "팀장으로 이어서 출근하기"로 팀장 모드(45세 시작)에 바로 이어진다.
- 메커닉·난이도 곡선·연도별 규칙은 팀장 모드와 동일하고 콘텐츠만 다르다 (`src/staff.ts`).
  - 공격: 선배 잔소리(직진) · 기습 회의(돌진) · 일 떠넘기기(3연속) · 거래처 전화(전화벨) · 팀장님 지시(흔들림) · 부장님 회식(2번 막기) · 동기 응원(회복)
  - 인물: 김선배·이대리·박과장·최주임·동기 / 팀장 / 옆팀장(차출 해) / 부장
  - 규칙 해: 성과급 0원 · 옆 팀 지원 차출 · 조직개편 · 번아웃 · 동기가 팀장으로 · 연말 회식 시즌(3번) · 마감 주간 · 팀장 승진 심사(부장님 "승진 면접")
  - 직급 표시: 사원(1~4년차) → 대리 → 과장 → 차장
- 막내 모드 칭호 15종 별도, 최고 기록·처음 본 공격도 모드별로 저장. 공유 이미지는 사직서 / **승진 발령장**.
