# Game Brief: 버텨라, 팀장님

> Claude Code Game Studios `game-brief.md` 템플릿(minimal rigor: 이 한 장이 설계 문서 전부).

**One-sentence pitch:** 사방에서 날아오는 팀원 불만·지각·고객 컴플레인·상사의 무리한 지시·사장의 희망퇴직 압박을 방패 하나로 막으며 45세 팀장이 60세 정년까지 버티는 한 손 방어 게임.

## Core loop
- 사무실 한가운데 팀장 주위로 공격(말풍선)이 날아온다 → 손가락/마우스 방향으로 방패를 돌려 막는다.
- 막으면 연속 방어 콤보로 멘탈 회복, 못 막으면 멘탈 감소. 팀원의 응원(커피·치킨)은 일부러 **막지 말고** 받아야 회복.
- 1년(약 20초)을 버티면 연말 인사평가에서 특전 1개 선택 → 다음 해에는 새 공격 유형이 섞이고 더 빨라진다.

## Player goal & fail state
- 목표: 60세 정년퇴임(15년 생존). 기록 = 버틴 나이.
- 실패: 멘탈 0 → "53세, 희망퇴직 압박에 무너졌습니다"처럼 마지막에 맞은 공격이 퇴사 사유가 된다.

## MVP
1. 방패 회전(포인터 방향 / ← →) + 원형 충돌 판정
2. 공격 7종: 불만(직선), 지각(느리다가 돌진), 업무 태만(3연속 떠넘기기), 고객 컴플레인(아무 방향에서 빠름), 불합리한 지시(좌우로 흔들리며 접근), 희망퇴직 압박(느리고 묵직, 두 번 막아야 함), 응원(회복, 막으면 손해)
3. 공격 전 예고 모션(공격자가 "!" 표시하며 흔들림)
4. 15년 연도 진행 + 연도별 이벤트(신입 입사, 상무 부임, 구조조정…)
5. 연말 인사평가 특전 3택1
6. 정년퇴임 / 퇴사 결과 화면 + 공유

## Out of scope
- 로그인·랭킹·서버 저장 없음(최고 기록만 기기에 저장)
- 그래픽 에셋 없음: 이모지 + 캔버스 도형
- 스토리 컷신, 캐릭터 커스터마이즈, 멀티플레이 없음

## Build order
1. 방패 + 직선 공격 1종으로 "막는 손맛" 확인 (가장 위험한 부분)
2. 공격 7종 행동 패턴 + 예고 모션
3. 연도 진행·난이도 곡선, 특전
4. 결과 화면·공유·사운드·진동 다듬기

---
**Who it's for / what they feel:** 직장인이 출퇴근길 폰으로 5분 — "아 이거 우리 회사네" 하며 웃고, 정년까지 버텼을 때 묘한 뿌듯함.

**Art & audio direction:** 밝은 사무실 톤의 플랫 일러스트 느낌(이모지 캐릭터 + 파스텔 말풍선), 짧은 8비트 효과음.

**Reference game:** 방패로 사방 공격을 막는 원형 방어 장르 — 그중 "중앙 고정 + 방패 회전" 루프만 가져오고, 이동·공격은 없음.
